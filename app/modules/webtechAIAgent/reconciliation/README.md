# Reconciliation questions

The chatbot in `webtech_editor` sends inventory questions to:

`POST /api/v1/reconciliation/ask`

```json
{ "message": "lavkush mein mustard kitna hai", "context": null }
```

Numbers come from live Odoo (`stock.move` and `stock.quant`). Any warehouse and any product can be asked. The answer shape stays the same: IN, delivered sale, RTO, expected on hand, live on hand, reserved, free, gap, outgoing, in transit, and cancelled demand.

The API reads Odoo with `ODOO_CRM_API_KEY`. Set `ODOO_JSON2_URL` (for example `https://com.gramik.in/json/2`) when the CRM base URL is local. The editor bridge uses `WEBTECH_FASTAPI_URL` (default `http://127.0.0.1:8010`).

## Supported

- Live on hand, reserved, and free from `stock.quant` (free is on hand minus reserved)
- Running on hand on a past day, from classified stock moves
- Expected on hand: IN + adjustment IN + RTO − delivered − adjustment OUT
- Reconciliation gap: live on hand minus expected
- Delivered sale for a day, range, or the loaded moves
- IN receipts, RTO received, outgoing assigned, cancelled demand
- In-transit location qty
- Follow-up questions that keep the previous warehouse, product, or metric
- More than one warehouse in the same question
- All products of one dark store as an Excel file, with the same tabs as the single-product workbook: Summary, Ledger, IN, Delivered, RTO, In Transit, Outgoing, Cancelled, Live Stock. Ask for example: `lavkush ke saare products ka reconciliation excel banao`. The file is written under Gramik-Live `data_reconciliation`. After that, say `isko manoj@gramik.in par mail kar do` and the same file is attached through Amazon SES. Any address works. Subject: `Excel Report Generated by WebTechAgent AI Assistant`.

If a name matches several warehouses or products, the reply asks for a number. If Odoo has no row, the reply says it was not found.

## Not calculated

- LMD picking. Delivered sale is not used as a substitute
- Weight in kg

Transit-leg quantity is not added again on top of the IN receipt.
Cancelled demand is not subtracted from stock.
Outgoing assigned qty stays inside on hand.
An empty `stock.quant` result is on hand 0, because Odoo has no quant row.
